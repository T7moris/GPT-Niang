# Bundled widget font

`LXGWWenKai-Medium.ttf` is the unmodified Medium font from
[LXGW WenKai v1.522](https://github.com/lxgw/LxgwWenKai/releases/tag/v1.522).
It is distributed under the [SIL Open Font License 1.1](OFL.txt).

WPF loads the font from this directory; no system font installation is needed.
The font is used for the Windows widget's Chinese text. Percentages continue to
use Segoe UI. The character artwork is unchanged.
