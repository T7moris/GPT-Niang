# Windows 角色主题色

入口：右键角色 → 外观设置 → 界面主题。

- 跟随角色配色：使用当前角色图片提取的代表色，切换角色同步气泡、菜单、滑块及人物库。
- 选择或自定义主题色：最多三个图片候选色，或输入 `#RRGGBB`；立即应用，按角色保存。
- 重新从当前图片取色：清除当前角色的手动色，重新计算候选色。
- 恢复默认紫色：关闭角色主题，保留每个角色的手动选择，方便重新启用。

角色位图、窗口层级和宿主焦点逻辑没有改动。原有台词/音乐动态变色仍可临时覆盖气泡颜色，动态效果结束后恢复角色主题。额度偏低的橙色和红色提示保留。

主题设置单独保存在数据目录的 `character-themes.json`，不改动原有 `settings.json` 的内容和格式。默认关闭，可在界面主题菜单中启用。

取色使用最多 64 × 64 像素的样本，忽略透明、近黑白灰像素并降低明亮肤色的权重。按色相的覆盖权重排序，不能理解发色、服装或角色语义，多色图片可能需要手动选择。灰度图片回退紫色。文字颜色单独压暗，以保持对比度。

只在角色首次启用主题或图片内容签名变化时取色；显式重新取色也会计算一次。签名使用受控角色图片的大小及最后修改时间。没有新增定时器、后台进程、输入钩子、网络请求或 ChatGPT/Codex 文件修改。

验证：

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File tests/character-theme.test.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File tests/character-theme-ui.test.ps1
```

这两项也已纳入原有 Windows 测试入口。
