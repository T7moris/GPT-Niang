# GPT 娘 · JavaScript 架构 Beta 测试版

版本：1.4.0-beta.3。本包仅适用于 Windows 10 / 11 x64，采用 JavaScript / Electron 界面与 Node.js 后台，并保留用于窗口识别、音频和安装的本地辅助程序。macOS 正式版仍使用原来的下载包。

这是 Beta 测试版，不是正式稳定版或 RC。正式版 1.3.6 用户不会被自动升级到这个测试版。

## 安装与使用

1. 下载名称包含 `windows-js.zip` 的完整安装包，解压到本地文件夹。不要在压缩包内直接运行。
2. 运行 `安装GPT娘.cmd`。安装器会先识别现有 GPT 娘插件，升级原程序目录并保留原个人数据目录；首次安装默认使用 `%USERPROFILE%\.gpt-niang` 下独立的程序和个人数据目录，避免不同入口的数据目录重定向。安装信息不确定时会停止，不会另建一套程序覆盖偏好。
3. 保持 Codex 桌面端已登录。安装完成后右键角色打开菜单；若安装前菜单已经打开，先关闭后再打开。

安装包已包含运行环境，不需要另装 Node.js。已有版本建议保持原安装目录可用，避免先删除旧目录导致安装记录无法识别。退出和启动仍使用原来的入口；不需要修改个人语录、形象或声音。

测试版后续升级目前仍以手动下载安装为主，自动更新只查询正式发布。当同一版本的正式版发布后，可按正常更新方式转到正式版。

## 本次内容

- 将 Windows 挂件迁移到 JavaScript / Electron，按现用功能保留额度、语录、自定义形象和音效、音乐律动、位置跟随、回答结束提醒与启动管理。
- 调整浅色和深色菜单的圆角、半透明材质、控件间距、键盘焦点及过渡动画；修正子菜单错位、小窗口裁切和错误提示被遮挡。
- 修正非活动角色窗口丢弃鼠标按下的问题：点击与拖动无需激活挂件窗口，也不抢键盘焦点。已在本机验证切换窗口后仍可操作。
- 安装与插件缓存保持一致，不保留整份旧程序备份；个人数据与程序文件分开存放。

## Beta.2：目录兼容、对话用量与第三方 API 估算

右键角色选择「用量与记账…」。可查看最近活动或手动选择的对话累计 tokens、最近一轮用量、今日记录与账本累计。聊天名称从所选 Codex 数据目录的本地索引只读获取；索引不可用时显示会话标识。自动选择表示最近有日志活动的对话，不能保证就是桌面当前选中的聊天；列表最多展示最近200条主对话。

在面板中选择自己的 Codex 数据根目录，文件夹不必叫 `.codex`。安装器和启动程序保留 `CODEX_HOME` / 原安装中的 `codexHome`；也可用 `安装GPT娘.cmd --codex-home "D:\我的 Codex 数据"` 指定安装归属。安装包外层文件夹可以改名，更新器通过程序身份与完整校验清单识别，仍会拒绝多个程序根目录、外部文件和校验失败。已安装程序直接搬家后仍需重新安装登记路径，不会猜测另一份安装的位置。

第三方 API 费用按服务商、模型及手动填写的每百万 tokens 单价估算，支持人民币和美元、普通输入、缓存读取、缓存写入及输出。缓存项留空时沿用普通输入单价；服务商/模型中的 `*` 表示通用规则，具体规则优先。不预设价格、不调用模型、不连接第三方账单接口，也不读取或上传 API 密钥。订阅额度无法由 tokens 准确换算，原官方额度气泡保持独立。

缓存是输入计数的一部分，推理是输出计数的一部分，不会额外重复相加。重复额度通知、派生聊天中的相同历史请求和归档移动会去重；继承但缺少原始计数、计数回退或未配置单价的部分会明确提示，不当成新花费。主对话卡片显示自身计数，账本也包含已扫描到的子代理请求。平台倍率、折扣、退款、取整及日志未记录的用量需要以平台账单为准。

统计在打开面板时由独立工作线程增量读取，关闭面板后回收线程。首次读取大量历史时会显示状态；本地仅新增一个轻量 SQLite 账本和一份单价设置，不复制聊天正文或整份数据目录，也不新增下载运行依赖。原额度和提醒轮询频率不变。

## Beta.3：稳定性与交互改进

- 完成提醒和用量账本共用分块首行读取，支持超过 64 KiB 的会话头、UTF-8 分块及尚未写完的首行。首行上限为 4 MiB，超限记录不计入，不保存启动指令正文；原读取频率不变。
- 后台启动宿主等待守护进程并传回退出码，错误摘要限制长度。升级先释放旧宿主占用的文件，再替换启动器；失败可恢复旧程序。
- 桌面置顶检查实际遮挡顺序，符合条件时无激活地恢复；尊重其他置顶窗口。
- 新安装使用稳定用户目录；已有安装继续保留原路径。仅在原安装、当前用户和启动入口身份吻合时重建缺失绑定，现存但不匹配的绑定仍会拒绝。
- 点击回答完成气泡可返回 Codex；自动提醒本身不会切换前台窗口。
- 增加独立的「点角色连续换语录」开关，默认关闭，原点击循环保持可用。
- 自动语录保留原预设，并可输入秒、分钟或小时，范围为 10 秒至 24 小时。

## 测试范围与剩余边界

已进行隐藏界面、缩放与菜单边界、保存失败反馈、键盘和滑块操作、更新事务与回退、自定义内容保留、窗口输入及资源清理等自动检查。本机曾出现角色收不到按下事件的问题，现已定位并修复，经过用户实际点击、拖动及切换窗口验证。

真实混合 DPI 跨屏、长时间交互负载、不同音频设备/歌曲和下一次真实登录启动仍需要继续验收。没有宣称已经完成长期稳定性验收，也没有宣称所有场景的内存和流畅度都优于旧架构。Electron 运行环境占安装包主要体积。

## 源码与构建

本分支的 `windows-js` 为本测试版源码；原来的 `gpt-niang-usage` 与 `macos` 保留正式版实现供对照。构建需要 Windows x64、Node.js 22.12 或更新版本、系统 .NET Framework C# 编译器，以及包含 MSVC x64 工具的 Visual Studio Build Tools。普通用户安装已打包的附件不需要这些编译工具。

```text
npm ci
npm run prepare:runtime
npm run compile:native
npm test
npm run package:beta -- --output ../dist/javascript-beta
```

公开构建只包含程序、内置素材和运行依赖，不读取或打包本机设置、登录信息、运行记录或个人自定义内容。校验文件为 `SHA256SUMS.txt`，源码提交记录在包内 `BUILD-INFO.json`。

软件与随附素材的许可、贡献和角色说明沿用仓库现有记录，请参见仓库 LICENSE 与正式版 README。
