# GPT 娘 1.4.0-beta.1 · JavaScript 架构测试版

这是 **Windows x64 的 JS / Electron 架构 Beta 测试版**，不是正式稳定版或 RC。目标是保留原版功能和个人设置，验证新架构及菜单交互。macOS 继续使用正式版 1.3.6。

下载 `gpt-niang-usage-widget-v1.4.0-beta.1-windows-js.zip`，完整解压后运行 `安装GPT娘.cmd`。安装包包含运行环境，无需另装 Node.js。安装器会识别现有插件并保留原个人数据目录；无法确认原安装时会停止。不要先删除原安装目录。

本次包括：额度与语录界面、自定义形象和音效、位置跟随、音乐律动、提醒与启动管理的 JavaScript 迁移；浅色/深色菜单、圆角和过渡动画调整；菜单错位、裁切和报错提示显示修正；非活动角色窗口吞掉鼠标按下事件的修复。鼠标处理使用小型本地辅助模块，点击拖动不抢键盘焦点。

正式版用户不会自动收到本测试版。Beta 后续更新目前以手动下载安装为主，自动更新仍只查询正式发布。
