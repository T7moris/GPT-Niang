# GPT 娘 1.4.0-beta.3 · JavaScript 架构测试版

Windows x64 的 JS / Electron 架构 Beta 测试版。本次逐项参考现有 PR，补齐四类稳定性问题和三项交互功能。Beta.2 的目录兼容、对话用量与本地费用估算继续保留，原读取频率不变。

- **长会话头**：完成提醒与用量账本支持超过 64 KiB 的首行，处理 UTF-8 分块和部分写入。首行上限 4 MiB，超限记录不计入，不保存启动指令正文。
- **后台启动**：无控制台宿主等待守护进程并传回退出码，错误摘要限制长度；升级会先释放旧宿主文件占用，失败可回退。
- **桌面置顶**：检查实际窗口遮挡顺序，符合条件时无激活地恢复，尊重其他置顶窗口。
- **路径与绑定**：新安装默认使用 `%USERPROFILE%\.gpt-niang`；已有安装保留原路径。仅在原安装、当前用户和启动入口身份吻合时修复缺失绑定。
- **完成提醒点击返回**：主动点击完成气泡可返回 Codex；自动提醒本身不会切换前台。
- **连续语录开关**：新增独立的「点角色连续换语录」，默认关闭，保留原点击循环。
- **自定义自动语录间隔**：保留预设，可输入秒、分钟或小时，范围 10 秒至 24 小时。

下载 `gpt-niang-usage-widget-v1.4.0-beta.3-windows-js.zip`，完整解压后运行 `安装GPT娘.cmd`。安装包已含运行环境，无需另装 Node.js。安装器识别原插件并保留个人数据目录，请不要先删除原安装。

**费用仅为本地估算**，不等于平台结算或官方订阅额度百分比；平台倍率、折扣、退款、取整和日志缺失均以实际账单为准。不读取 API 密钥，不连接第三方账单接口，不调用模型。首次历史扫描完成前累计数据仍在变化。

真实混合 DPI 跨屏、长时间交互负载、不同歌曲/设备及下一次真实登录启动仍需继续观察。详细使用方法和计数边界见 `windows-js/README.md`。
