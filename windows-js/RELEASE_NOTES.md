# GPT 娘 1.4.0-beta.4 · 开发候选

本候选尚未发布或安装。Windows x64 的 JS / Electron 架构，保留 Beta.3 的全部功能和个人数据格式，原额度刷新与窗口读取频率不变。

- **额度查询收尾**：专用 App Server 使用子进程参数关闭插件初始化，不改用户全局配置。收到结果后先关闭输入并等待退出，超时才逐级结束，退出清理有界。关闭挂件时通知所属 worker 清理进行中的查询。尚未测量真实长期网络流量变化。
- **连点音效**：新点击立即起音，旧声音约 8 毫秒平滑收尾，最多保留两个收尾音源。静音、换音与退出时清理节点和定时器，不合并点击、不积压补播。已验证离线 PCM 包络，实际设备听感仍需验收。
- **一键重启**：菜单和 `重启GPT娘.cmd` 共用身份检查和重启流程。先检查当前用户、安装、启动绑定、编辑状态及更新状态；由独立的一次性后台任务停止并启动本安装，结束后清理临时入口。保留个人文件，重复请求合并，失败保留可读诊断。
- **重启交接保护**：请求等待期间发生退出、停用或暂停状态变更时取消本次重启，保留后续操作；检查状态文件异常时也释放更新/重启锁。
- **电池供电重启**：一次性重启助手与守护任务使用相同的供电设置，不因笔记本使用电池或拔下电源而被默认规则阻止或终止。
- **隐藏测试窗口防护**：修复验证台最小化/恢复绕过隐藏拦截、显示离屏占位窗口的问题。所有候选测试窗口经过统一保护；模拟最小化/恢复时不调用真实系统显示操作，完整交互验证持续检查 Win32 可见性。正常挂件不启用这项测试防护。
- **可见测试显式开启**：普通测试跳过会显示真实挂件的渲染崩溃验收，仅在明确设置 `GPT_NIANG_VISIBLE_TESTS=1` 后执行，防止测试过程打断桌面使用。
