# GPT 娘 1.4.0-beta.2 · JavaScript 架构测试版

Windows x64 的 JS / Electron 架构 Beta 测试版。保留 Beta.1 的菜单、角色交互及功能迁移，本次增加目录兼容、对话用量和第三方 API 本地费用估算。macOS 继续使用正式版 1.3.6，正式版用户不会自动收到本测试版。

- **目录名称兼容**：支持改名后的安装包外层文件夹；更新包按程序身份和完整校验清单识别。安装、启动与升级保留自定义 `CODEX_HOME`，用量面板也可选择不同名称的 Codex 数据目录。不会自动寻找或接管已经搬家的其他安装。
- **对话用量**：查看所选对话累计 tokens、最近一轮、今日记录和账本累计；可按服务商筛选或手动选择对话，聊天索引只读获取标题。自动选择的是最近有日志活动的对话。
- **第三方 API 估算**：按服务商/模型设置每百万 tokens 的普通输入、缓存读取、缓存写入与输出单价，支持人民币和美元。未设置单价时只显示用量，不编造价格。
- **去重与资源回收**：缓存、推理计数不重复相加；重复通知、相同派生历史、归档和重启不会重复记账。无法验证的继承用量或计数回退会提示。历史扫描在独立工作线程中进行，关闭面板即回收，不改原轮询频率。

下载 `gpt-niang-usage-widget-v1.4.0-beta.2-windows-js.zip`，完整解压后运行 `安装GPT娘.cmd`。安装包已含运行环境，无需另装 Node.js。安装器识别原插件并保留个人数据目录，请不要先删除原安装。

**费用仅为本地估算**，不等于平台结算或官方订阅额度百分比；平台倍率、折扣、退款、取整和日志缺失均以实际账单为准。不读取 API 密钥，不连接第三方账单接口，不调用模型。首次历史扫描完成前累计数据仍在变化。

真实混合 DPI 跨屏、长时间交互负载、不同歌曲/设备及下一次真实登录启动仍需继续观察。详细使用方法和计数边界见 `windows-js/README.md`。

附件包含安装包与 `SHA256SUMS.txt`；包内 `BUILD-INFO.json` 记录源码提交。Beta.1 和 v1.3.6 的既有发布附件保持不变。
