# Windows 本地音效与 Q 弹音响

右键角色，打开「声音与点击」。这两个功能独立工作。

## 导入自己的点击音效

选择「导入按下 / 松开音效…」，依次选取按下和松开时播放的两段 WAV。
支持 8/16 位、单声道或双声道、8–192 kHz 的 PCM WAV，每个文件不超过 2 MB、10 秒。
两段都通过检查后才替换当前选择；取消选择或导入失败会保留原有音效。
导入完成不会试听或自动播放；下次正常按压角色时使用新音效。静音和音量设置继续生效。

「原版音效」可随时恢复默认；「本地音效」切回最后一次成功导入的组合。
导入的文件复制到现有用户数据目录的 `custom-sounds` 子目录，重启后仍可使用，应用更新不会覆盖它们。
重新导入会保留旧文件及上一份清单备份；清理前请退出挂件，并自行保留需要的音效。
加载时若文件丢失或格式检查失败，会回退到原版音效；播放过程中若解码报错，也会切回原版，下次点击生效。

仓库和发布包不包含第三方小黄鸭音效、歌曲或用户导入的文件。可在自己的电脑上导入已取得使用许可的音效。

## 搬出音响

勾选「搬出音响，一起 Q 弹」：矢量音响从角色身后弹出，角色和音响轻微伸缩。
动画不会自动播放音乐，也不更改额度气泡、语录和窗口位置；音响不接收鼠标事件。
再次点击即可收回。窗口隐藏时停止动画，重新显示时恢复；退出或重启后默认关闭。

本次实现仅针对 Windows WPF。macOS 原生界面未增加这些入口。

## GPT，移动

在「声音与点击」中勾选「GPT，移动」，挂件会沿原有高度左右移动，到边缘减速折返。
跟随窗口时在当前窗口可见区域内移动，桌面模式下在工作区内移动，不改写保存的位置。
鼠标移到挂件上、打开菜单或隐藏窗口时暂停；手动拖动会退出自动移动。
再次点击开关回到原停靠位置，每次启动默认关闭。它可以和音响 Q 弹一起使用。
