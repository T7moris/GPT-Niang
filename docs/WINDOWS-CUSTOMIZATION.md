# Windows 形象选择与使用说明

为桌面挂件选择喜欢的形象，或添加自己的图片。形象切换后会自动保存，下次启动继续使用。

## 选择形象

右键点击龙娘，依次打开「外观设置」→「形象」，选择想使用的形象。

## 添加与移除

点击页面底部的「＋ 添加形象」卡片，选择本地图片。推荐使用透明背景 PNG，让人物边缘更自然；其他图片会保留原有背景，并按比例显示。

支持 PNG、JPG / JPEG、BMP、GIF。GIF 仅显示第一帧，不播放动画。单张图片上限为 20 MB，宽高均不超过 4096 像素，总像素不超过 1600 万。

导入会保存图片副本，因此之后移动原图不会影响已添加的形象。

点击自定义形象卡片上的 − 可移除，操作后可选择「撤销移除」。内置形象无法移除；移除当前形象，或所选图片无法读取时，会恢复默认的「龙娘1」。

## 缩放与额度显示

在「外观设置」中调整挂件大小。缩小时，人物轮廓采用更平滑的显示方式；图片始终保持比例。

额度气泡根据单行或双行信息调整布局，文字和进度条更容易阅读。刷新按钮位于气泡下方，点击即可更新额度。

## 平台与版本

形象选择与上述界面改进目前提供于 Windows 源码，现有 1.3.4 正式安装包尚未包含。获取源码后，将项目放到准备长期保留的位置，在根目录运行 `安装GPT娘.cmd`；需要 Node.js 20 或更新版本及已登录的 Codex 桌面端。其他安装说明见[项目主页](../README.md#windows-安装)。
