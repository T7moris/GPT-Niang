# Windows 角色库、低额度形象与音效整合

本次将 AkihiM 的角色库与显示修复、LY1A 的低额度形象与连续 PCM 音效整合到上游 main，并补齐两者共存时的状态切换和回归测试。此处记录来源与最后的行为，原贡献者的 PR 继续独立评审。

## 来源

- AkihiM：[PR #34](https://github.com/T7moris/GPT-Niang/pull/34)，参考 `feature/windows-character-library` 的 `5bcdd3b19cd450bfe9765c830cf8ea1e8c421e2d`。角色导入/选择/移除与撤销、高质量缩放、按比例显示与透明点击、紧凑额度气泡、小数音量记忆，以及12句扩充台词来自这一分支。
- LY1A：[PR #42](https://github.com/T7moris/GPT-Niang/pull/42)，参考 `main` 的 `89d626f0e88dcdd8fc4e8c06c8825fc23d994224`。低额度形象、12句独立台词、编辑与预览，以及较新连续 PCM 音频引擎来自这一分支。
- 本次贡献者：整合包与额外普通5句、低额度9句，共14句；补齐低额度覆盖与所选形象恢复、保存失败回滚，以及两边测试的兼容。

## 共存行为

角色库保存正常形象选择；5小时或每周任一有效窗口剩余≤5%时临时显示独立耗尽形象。恢复后返回保存的形象。在低额度期间选择新角色，会保存选择并继续显示耗尽形象，恢复后显示新选择。结束测试预览同样返回所选角色。

切换时同步图片、透明点击映射、大小/位置和颜色蒙版。设置保存失败时回滚选择和显示，不留下混合状态。图片采用 Uniform 完整显示和高质量缩放。

音频使用 LY1A 较新的连续 PCM 输出实现，保留完整按下/松开顺序、快速点击重触发、静音/音量、故障恢复和退出释放；小数音量设置的恢复沿用 AkihiM 修复。

普通台词为50句（原上游33句+AkihiM12句+本次5句），低额度台词为21句（LY1A12句+本次9句）。已有自定义台词仍保存于用户数据目录；通过界面恢复内置台词后使用新列表，恢复前会保留备份。

## 范围与验证

新增交互仅在 Windows WPF/PowerShell 实现；macOS 原生源码、共享额度读取协议和官方更新源保持上游实现。普通台词文件由双平台共享。安装包中没有用户绝对路径、安装配置、日志、运行状态或导入的私人图片。

执行共享 Node 测试、完整 Windows 回归和 Windows 打包检查。Windows 测试包含角色库/导入/撤销/回退、低额度边界与账号隔离、真实 WPF 图片与 alpha 命中、颜色蒙版、预览结束、低额度期间选择、设置写失败回滚、两种朝向与多档 DPI/缩放，以及原生静音 PCM 连续点击压力。语录检查覆盖所有50句普通、21句低额度和200字符自定义文本的实际 WPF 字形边界。

本机为 Windows；macOS 的 Swift 测试与真机交互需要由现有 CI 或维护者验证。自动化音频使用静音 PCM，不等于主观听音检查。
