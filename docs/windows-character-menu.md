# Windows 图片更换与菜单

1.3.5 已包含图片更换、独立大小与图库操作。

右键角色，选择「更换形象」，再点「添加形象」导入电脑上的 PNG、JPG、BMP 或 GIF。GIF 使用第一帧；推荐透明背景 PNG。导入的图片会复制到个人数据目录，移动原文件后仍可使用。

点选图片立即切换，重启后保留选择；无法读取上次选择的图片时恢复默认龙娘。导入失败保留当前图片，移除导入形象后可撤销，默认形象始终保留。图库打开期间，更新器等待它关闭后再安装。

主菜单顺序为：查看额度、刷新额度、换一句台词；更换形象、外观设置、声音与点击、编辑我的语录、自动语录；显示与位置、更新；退出 GPT 娘。

图片等比例显示并使用高质量缩放。音量读取保留 0～1 的小数，例如 37% 重启后仍为 37%。

外观菜单提供人物、气泡两项独立大小。旧设置首次加载时保留原来的整体比例；例如可主动调整为人物 60%、气泡 100%。拖动大小滑块时菜单临时变淡，调整气泡时显示预览，松手或取消后恢复原状态。人物变色层随人物同步布局，刷新按钮留在气泡内。此方案参考 [Rhodoeos 的 PR #23](https://github.com/T7moris/GPT-Niang/pull/23)，补齐与图片更换及变色效果的配合。

图片图库、导入／回退和相关测试参考 [AkihiM 的 PR #34](https://github.com/T7moris/GPT-Niang/pull/34)，高质量缩放也见 [Ifinty 的 PR #28](https://github.com/T7moris/GPT-Niang/pull/28)。

点击音效使用系统 SoundPlayer 播放内置 WAV，不依赖 Windows Media Player。播放数据预加载，按设置缩放音量；退出或重新初始化时释放缓存。声音方案参考 [ytzha 的 PR #29](https://github.com/T7moris/GPT-Niang/pull/29)。菜单按钮采用三条矢量线段，参考 [Aprogues 的 PR #35](https://github.com/T7moris/GPT-Niang/pull/35)，不引入该 PR 的附带字体或气泡重排。保存的窗口位置也保留小数。

自动语录默认关闭。在「自动语录」菜单开启后，可选择1、5或15分钟间隔。只在挂件可见且气泡收起时计时；拖动、缩放预览、菜单或编辑窗口会暂停，重新显示和休眠恢复后重新计时，不补弹。直接显示语录，约5秒收起，不额外刷新额度；手动查看额度保持原有行为。计时方案参考 [PR #30](https://github.com/T7moris/GPT-Niang/pull/30)，补齐恢复时机与当前独立缩放／形象库的配合。
