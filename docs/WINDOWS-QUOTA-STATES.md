# Windows 低额度形象与独立台词

5 小时或周额度任一窗口剩余 **5% 及以下**（包括 0%），挂件自动切换到全身耗尽形象，并从独立台词库抽取台词，例如“需要重置……”。所有有效目标窗口都恢复到 5% 以上后，恢复用户在角色库选择的正常形象与普通台词。仅有周额度的账号也支持；其他时长和公司个人金额限额不触发这条规则。

打开中的语录气泡会同步更新，无需再次点击。额度页面仍保留原项目的布局和操作；查询频率、接口、联网方式、安装登记和 macOS 原生界面均不变。

## 预览与编辑

- 在「外观设置 → 额度耗尽形象（测试）」查看耗尽形象和台词，再点一次恢复按实际额度判断；重启也会退出预览。预览期间继续跟踪真实额度状态。
- 在「编辑我的语录」左下角点「管理额度耗尽语录」，编辑独立列表，支持 `3 | 需要重置……` 形式的权重。
- 普通台词使用用户数据目录的 `quotes.json`，耗尽台词使用 `quotes-low-quota.json`。保存或恢复耗尽台词不覆盖普通台词；覆盖和恢复前保留备份。

## 数据与图片

仅成功且不超过三分钟的额度快照用于新的判断。已过重置时间的旧窗口不视为额度归零。读取失败、损坏文件和过期数据保留最后确认的状态；账号身份变化或后端明确要求清除旧账号时清除旧状态。读取失败不会被当作额度耗尽，也不会自行把额度恢复为 100%。

界面从既有本地状态文件判断，不新增请求或账号数据。此实现整合 LY1A 的低额度能力与 AkihiM 的角色库。低额度期间切换图库选择不会解除耗尽状态，恢复时使用最新保存的选择；图片、命中图和颜色蒙版同步更新。

耗尽素材为 1254 × 1254 的透明 PNG，按 228 × 228 设计尺寸显示（相对 208 × 208 约增大 10%），保持横向中心并按不透明边缘对齐脚底。恢复时还原原项目 208 × 208 的尺寸和位置；图片、透明点击映射和颜色蒙版同步切换。

`gpt-dragon-low-quota.png` 由贡献者提供角色参考，通过 ImageGen 清晰化、重绘细节、抠图及配色调整后得到；属于角色素材而非 MIT 代码。沿用 [角色与图片素材声明](../gpt-niang-usage/assets/CHARACTER-NOTICE.txt)，参考图及角色设计的第三方权利不因本次提交而转移。

## 验证

运行 `npm run test:windows`，包含额度边界、异常数据、独立台词管理、实际状态文件到 WPF 图片和已打开气泡的切换、图片透明点击映射、颜色蒙版、预览和恢复，以及原项目安装、更新、生命周期和界面回归。完整启动检查分别覆盖两个窗口恰好 5% 与两项恢复。

共享后端保持不变，可运行 `npm test`；macOS 未在本次 Windows 环境运行 Swift 或真机检查。真实账号归零属于外部条件，边界行为用隔离快照验证，不等于所有桌面交互均完成真机验收。
